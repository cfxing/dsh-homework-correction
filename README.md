# 作业批改 · 移植包（窗口1）

看到本文件说明你已经拿到完整包：**先读 `使用说明.md`**（安装步骤、文件说明、配置与排错都在里面）。

极速上手：

1. 装 Node.js（跑 `作业批改-启动中转.bat`）和 Python（先双击 `作业批改-安装OCR环境.bat`，再跑 `作业批改-启动OCR.bat`）。
2. 双击两个启动 bat，让 8899 / 8897 两个本机服务跑起来。
3. 把这个文件夹当项目目录打开 DSH 工作台，窗口1 会自动挂载 `窗口1-作业批改工作台.html`。
4. 进窗口1 → 拍照或上传 `示例-物理填空题.jpg` → 点「开始批改」。

识别服务（阿里云百炼 / `qwen3-vl-plus`）的 API Key 已内置在页面里，开箱即用；**请勿把本包公开分享**（Key 是明文）。
