# dsh-homework-correction · DeepSeek Harness 作业批改

将原有「拍照/上传作业 → 识别题目与手写答案 → 判定正误 → 原图批注 → 讲解知识点」流程整理为 DeepSeek Harness 可使用的作业批改工作流。

> 当前分支是 Harness 适配开发分支。原始 HTML 工作台保留作参考；旧版本机 OCR 服务是可选兼容组件，不再是必需依赖。模型视觉能力优先承担题目和手写答案识别。

## 目标工作流

1. 接收作业照片、扫描件或用户粘贴的图片。
2. 由当前 Harness 会话中支持图片输入的模型直接读取印刷题目、手写答案、图表和公式；不支持视觉输入时明确提示用户配置视觉模型，不静默伪造 OCR 结果。
3. 逐题提取题干、学生作答、标准答案/推导、判定、置信度和识别疑点。
4. 独立复核初判为错误或低置信度的题；题目或手写内容无法确认时标记「存疑」，不直接算错。
5. 给出步骤化解析、错因、相关知识点和针对性练习。
6. 在支持图像标注的执行环境中生成原图批注；否则提供题号、判定和位置描述，并输出可下载的 Markdown/JSON 报告。
7. 允许教师修改识别文本或判定，再重新计算报告。

## 重要安全说明

旧版 HTML 工作台的历史说明提到模型 API Key 曾写在页面中。**不要继续使用或发布含有明文密钥的旧版页面**。如该密钥曾被提交到公共仓库，请立即在模型服务控制台撤销/轮换，并从后续版本改为使用 Harness 的凭据配置或本机环境变量。不要把密钥写入 HTML、Skill、日志或提交记录。

## 开发与使用

开发基准为 DeepSeek Harness `0.2.0-rc.2`，以当前使用的源码版 Harness 为准。

- Skill 工作流：`skills/homework-correction/SKILL.md`
- 原始单页 UI 与 OCR/中转脚本：保留用于参考和后续迁移，不应将 Windows `.bat` 或独立 OCR 服务作为 Harness 的硬性依赖。
- 图片识别：优先调用 Harness 当前会话所配置的视觉模型。模型是否支持图像输入取决于用户的模型/提供商配置。
- 本项目不应把模型输出视为绝对正确；低置信度或图像模糊时应请求用户确认。
