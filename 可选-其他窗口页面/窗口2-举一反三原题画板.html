题目档案

题目名称5. 已知 F₁, F₂ 是椭圆 C: x²/9 + y²/4 = 1 的两个焦点，点 M 在 C 上，则 |MF₁|·|MF₂| 的最大值为（　　）
学科 / 年级高中数学 · 解析几何（圆锥曲线 · 椭圆的定义与焦半径）
题型单项选择题（最值问题）
难度中等（定义 + 基本不等式两步到位；易错在 a、b、c 混淆与忘记验证取等位置）
题干原文5. 已知 F₁, F₂ 是椭圆 C: x²/9 + y²/4 = 1 的两个焦点，点 M 在 C 上，则 |MF₁|·|MF₂| 的最大值为（　　）
A. 13　　B. 12　　C. 9　　D. 6
题干要点已知：椭圆 x²/9 + y²/4 = 1（a = 3, b = 2, c = √5）、两焦点 F₁, F₂、M 在椭圆上；所求：|MF₁|·|MF₂| 的最大值（两焦半径之积）。
关键：椭圆定义给出 |MF₁| + |MF₂| = 2a = 6 是定值，和为定值求积的最大值 ⇒ 均值不等式 mn ≤ ((m+n)/2)² = 9；等号在 |MF₁| = |MF₂| = 3（M 为短轴端点 (0, ±2)）时取到。
易错：A 项 13 = a² + b²、B 项 12 = 2ab、D 项 6 = 2a，分别对应"a、b 混算""错用 2ab""把和当积"三类典型错误。
（识图备注：图中 |MF₁| 与 |MF₂| 之间是乘点「·」，已按像素核对，不是减号。）
正确答案C（9）—— |MF₁|·|MF₂| ≤ a² = 9，当 M 在短轴端点 (0, ±2) 时取等；详见窗口3

核心知识点

椭圆定义：M 在椭圆上 ⇒ |MF₁| + |MF₂| = 2a = 6（本题的“和为定值”）
a、b、c 关系：x²/9 + y²/4 = 1 ⇒ a = 3, b = 2, c = √5，|F₁F₂| = 2c = 2√5
基本不等式：mn ≤ ((m+n)/2)² ⇒ |MF₁|·|MF₂| ≤ a² = 9（本题主方法）
取等位置：|MF₁| = |MF₂| = a = 3 时 M 在短轴端点 (0, ±2)，等号确实能取到
焦半径范围与配方视角：|MF₁| ∈ [3−√5, 3+√5]，设 |MF₁| = 3+t ⇒ 积 = 9 − t² ∈ [4, 9]
焦点三角形：|F₁F₂| = 2c，面积 = ½·2c·|y_M|，配合余弦定理可互求积、夹角、面积、平方和

解题方法与步骤

1
审题：先读出 a、b、c由 x²/9 + y²/4 = 1 得 a = 3、b = 2、c = √5（a² = b² + c²），|F₁F₂| = 2√5；M 在椭圆上 ⇒ |MF₁| + |MF₂| = 2a = 6
2
转化：和为定值求积记 m = |MF₁|、n = |MF₂|，问题化为"m + n = 6 时 mn 的最大值"，即均值不等式的标准场景
3
求解：均值不等式mn ≤ ((m + n)/2)² = (6/2)² = 9
4
检验取等并对照干扰项等号要求 m = n = 3：取 M(0, ±2)，此时 |MF₁| = |MF₂| = √(5 + 4) = 3 ✓；干扰项 13 = a² + b²、12 = 2ab、6 = 2a ⇒ 选 C
方法名称椭圆定义 + 均值不等式（配焦半径参数化、余弦定理）
适用条件椭圆上一点到两焦点的距离之积 / 平方和 / 夹角 / 焦点三角形面积的最值问题；核心是"两焦半径之和恒为 2a"这个定值
易错提醒① 关系式记错：本题是 a² = b² + c² ⇒ c = √5（不是 c² = a² + b²）；② 用完均值不等式不验证等号，漏掉"M 在短轴端点"这一位置；③ 把 |MF₁|·|MF₂| 与 |MF₁| + |MF₂| 混为一谈（后者恒为 2a，是定值不是最值）；④ 干扰项 13 = a² + b²、12 = 2ab、6 = 2a，全都来自 a、b、c 混用

变式一 · 换数字/换情境已生成

题目
已知 F₁, F₂ 是椭圆 x²/25 + y²/16 = 1 的两个焦点，点 M 在椭圆上，求 |MF₁|·|MF₂| 的最大值。
考查点
椭圆定义（两焦半径之和 = 2a）+ 均值不等式（a 变大，答案随之变为 a²）
解题要点
a = 5 ⇒ |MF₁| + |MF₂| = 10 ⇒ 积 ≤ (10/2)² = 25；等号在 |MF₁| = |MF₂| = 5，即 M 为短轴端点 (0, ±4)
答案
25（= a²）

变式二 · 逆向/条件互换已生成

题目
已知 F₁, F₂ 是椭圆 x²/9 + y²/4 = 1 的两个焦点，点 M 在椭圆上，求 |MF₁| − |MF₂| 的最大值。
考查点
三角不等式 |MF₁| − |MF₂| ≤ |F₁F₂| = 2c；与“积的最大值”作对照
解题要点
差的绝对值不超过焦距 2c = 2√5；M 在长轴端点 (3, 0) 时取到（此时 |MF₁| = 3 + √5、|MF₂| = 3 − √5）
答案
2√5（注意：积最大在短轴端点，差最大在长轴端点）

变式三 · 综合/拔高已生成

题目
已知 F₁, F₂ 是椭圆 x²/9 + y²/4 = 1 的焦点，M 在椭圆上。(1) 若 ∠F₁MF₂ = 90°，求 |MF₁|·|MF₂|；(2) 若 |MF₁|·|MF₂| = 8，求 △MF₁F₂ 的面积。
考查点
焦点三角形：定义 m + n = 2a 与余弦定理 / 勾股定理联立（两问互为逆命题）
解题要点
(1) m + n = 6，m² + n² = |F₁F₂|² = 4c² = 20 ⇒ mn = (36 − 20)/2 = 8；(2) 由 mn = 8、m + n = 6 得 m² + n² = 20 = 4c² ⇒ ∠F₁MF₂ = 90°，S = ½mn = 4
答案
(1) |MF₁|·|MF₂| = 8；(2) △MF₁F₂ 的面积 = 4
