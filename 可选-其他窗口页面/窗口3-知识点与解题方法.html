本题知识点

知识点所属章节在本题中的考查方式掌握要求
椭圆的定义（第一定义）
M 在椭圆上 ⟺ |MF₁| + |MF₂| = 2a		选择性必修一 · 圆锥曲线本题第一步：把两个焦半径之和固定成定值 2a = 6，为"和为定值求积"铺路必须熟练
椭圆中 a、b、c 的关系
a² = b² + c²		椭圆的标准方程由 x²/9 + y²/4 = 1 得 a = 3、b = 2、c = √5，焦距 |F₁F₂| = 2c = 2√5熟练（本题易错点）
基本不等式（均值不等式）
mn ≤ ((m+n)/2)²		必修一 · 基本不等式本题主方法：|MF₁|·|MF₂| ≤ ((2a)/2)² = a² = 9，直接得到最大值熟练
取等条件与几何位置圆锥曲线 · 焦半径等号要求 |MF₁| = |MF₂| = a = 3，此时 M 在短轴端点 (0, ±2)（此时 √(c² + b²) = √9 = 3 ✓）会用（必须验证）
焦半径的范围与配方视角
|MF₁| ∈ [a − c, a + c]		解析几何 · 焦半径设 |MF₁| = 3 + t 则 |MF₂| = 3 − t，积 = 9 − t² ∈ [b², a²] = [4, 9]（t = 0 最大、|t| = c 最小）会用（秒杀技巧）
焦点三角形的性质
|F₁F₂| = 2c，面积 = ½·2c·|y_M|		解析几何 · 焦点三角形变式与综合题里"乘积 ↔ 夹角 ↔ 面积 ↔ 平方和"的相互转化全靠 m + n = 2a 与余弦定理会用（变式核心）
干扰项识别
13 = a² + b²，12 = 2ab，6 = 2a		应试策略（非教材条目）三个错误选项正好对应"a、b 混算""错用 2ab""把 2a 当成积"三类典型错误，能反推考点理解出题意图

一句话脉络：椭圆定义给出"焦半径之和 = 2a"⇒ 和为定值求积的最大值 ⇒ 均值不等式得 a² = 9 ⇒ 验证等号在短轴端点能取到。记住三个"最值"的位置：积最大 a²（短轴端点）、差最大 2c（长轴端点）、焦半径范围 [a−c, a+c]。

知识点是这样拆出来的

① 看题干符号：写成 A = {a₁, …, aₙ} 且下标到 n ⇒ 元素两两不同（第一条前置知识）
② 看选项分层：A、B 是 n = 2，C 是 n = 3，D 是 ∀n ≥ 4 ⇒ 必须按 n 分类讨论
③ 看等式类型：乘积 = 和 ⇒ 小 n 可直接解，大 n 只能用不等式放缩
④ 看"存在 / 至多 / 有且只有"等措辞 ⇒ 分别对应构造、上界估计、唯一性证明三种任务

通用解题思路（五步，任何题都能套）

1
审题：圈条件、标所求抓住"椭圆方程""M 在椭圆上""求两焦半径之积的最大值"三件事，先把 a、b、c 与焦距写出来。
2
转化：把文字变成式子或图形记 m = |MF₁|、n = |MF₂|，由定义得 m + n = 2a（定值），把几何问题变成"和为定值求积的最大值"的代数问题。
3
定法：选模型与方法和为定值求积 ⇒ 均值不等式；涉及夹角或面积 ⇒ 余弦定理 + 焦点三角形；要把距离与坐标挂钩 ⇒ 焦半径公式 r = a ± ex。
4
求解：规范书写、步步有据写出 a² = b² + c² 的取值依据；用不等式后必须单独说明等号能否取到（本题取 M 为短轴端点）。
5
检验：回代与反思把 M(0, 2) 代回验证 |MF₁| = |MF₂| = 3；再检查是否与"差最大 2c""焦半径范围 [a−c, a+c]"等结论混淆。

本题思路链

椭圆 C: x²/9 + y²/4 = 1　→　a = 3, b = 2, c = √5（a² = b² + c²），|F₁F₂| = 2c = 2√5
点 M 在 C 上　→　由椭圆定义：|MF₁| + |MF₂| = 2a = 6（定值）
求 |MF₁|·|MF₂| 的最大值　→　记 m = |MF₁|, n = |MF₂|，则 m + n = 6，由均值不等式 mn ≤ ((m + n)/2)² = 9
验证等号：需 m = n = 3，此时 M 在短轴端点 (0, ±2)，而 √(c² + b²) = √(5 + 4) = 3 ✓，等号可以取到
所以 |MF₁|·|MF₂| 的最大值为 9，选 C（干扰项 13 = a² + b²、12 = 2ab、6 = 2a）
突破口所求是两焦半径之积，而椭圆定义给出两焦半径之和为定值 2a —— “和为定值求积的最大值”就是均值不等式的标准场景
关键一步|MF₁|·|MF₂| ≤ ((|MF₁| + |MF₂|)/2)² = ((2a)/2)² = a² = 9，并验证 |MF₁| = |MF₂| = a 确实能在短轴端点取到
为什么这样想椭圆上任意一点到两焦点距离之和恒为 2a，这是椭圆题里最稳定的“定值”；只要题目出现 |MF₁|、|MF₂| 的和、积、平方和、夹角、焦点三角形面积，先把 m + n = 2a 写下来，再用均值不等式或余弦定理
同类题信号“点 M 在椭圆上，求 |MF₁|·|MF₂| / |MF₁|² + |MF₂|² / ∠F₁MF₂ / △MF₁F₂ 面积” ⇒ 统一设 m = |MF₁|, n = |MF₂|，用 m + n = 2a、|F₁F₂| = 2c 搭配均值不等式或余弦定理
易混对照积的最大值是 a²（M 在短轴端点，此时两焦半径相等）；差的最大值是 2c（M 在长轴端点）；两焦半径的取值范围是 [a − c, a + c] —— 三个结论的取等位置各不相同，别记混
前两张是本题主方法；后面是通用方法工具箱（任何题都可能用到）。

椭圆定义 + 均值不等式本题主方法

适用求 |MF₁|·|MF₂| 的最大（小）值
要点m + n = 2a = 6 ⇒ mn ≤ ((m + n)/2)² = a² = 9；等号 m = n = a，此时 M 在短轴端点

焦半径参数化（配方）本题用

适用需要取值范围，或要说明取等位置
要点设 |MF₁| = a + t，则 |MF₂| = a − t（|t| ≤ c）⇒ mn = a² − t² ∈ [b², a²]，一眼看出两端点

椭圆定义（通用）通用

适用一切涉及两焦半径的椭圆题
要点先把 m + n = 2a 写下来；焦点三角形周长 = 2a + 2c，这是最稳的“定值”

余弦定理 + 焦点三角形通用

适用已知夹角、面积或平方和
要点|F₁F₂|² = m² + n² − 2mn·cosθ 与 m + n = 2a 联立；面积 = ½mn·sinθ = b²·tan(θ/2)

焦半径公式 r = a ± ex通用

适用要把焦半径与坐标挂钩（求点坐标、面积）
要点e = c/a = √5/3 ⇒ mn = 9 − (5/9)x²；再由 x² = 9(1 − y²/4) 得 mn = 4 + (5/4)y²

最值位置对照提醒

适用判断最值在长轴还是短轴端点
要点积最大 a²（短轴端点）｜差最大 2c（长轴端点）｜焦半径范围 [a − c, a + c]

本题所用方法

方法适用条件关键步骤易错点
椭圆定义 + 均值不等式（主方法）求 |MF₁|·|MF₂| 的最大值m + n = 2a = 6 ⇒ mn ≤ ((m + n)/2)² = 9，等号当 m = n = 3不验证等号可取（须指出 M 在短轴端点）；把 2a 记成 a
焦半径参数化（配方）要求取值范围或说明取等位置设 |MF₁| = 3 + t，则 |MF₂| = 3 − t ⇒ mn = 9 − t²，t = 0 取最大、|t| = c 取最小不写 t 的范围（|t| ≤ c = √5）就谈最值；误以为 t 可任意大
焦半径公式 r = a ± ex要把焦半径与坐标挂钩（求 M 坐标、面积）e = c/a = √5/3 ⇒ mn = 9 − (5/9)x²；再由 x² = 9(1 − y²/4) 得 mn = 4 + (5/4)y²左右焦点与 ± 号对应错；把 e 算成 b/a
余弦定理 + 焦点三角形已知夹角、面积或平方和|F₁F₂|² = m² + n² − 2mn·cosθ，与 m + n = 2a 联立；面积 = ½mn·sinθ把 2c 当成 c 用（本题 2c = 2√5）；面积漏乘 sinθ
面积公式 S = c·|y_M|由面积反求位置，或由位置求面积S = ½·2c·|y_M| = √5·|y_M|；反之由 S 定 |y_M| 再回代椭圆方程忘记系数 ½；把 |y_M| 与 |x_M| 用混
